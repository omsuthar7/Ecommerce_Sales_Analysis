## 📌 About the Project

**Ecommerce Sales Analysis** is a data analysis project built with Python to explore an e-commerce sales dataset and extract meaningful insights about **customers, purchasing behavior, locations, demographics, and product categories**.

The project uses data cleaning, exploratory data analysis (EDA), aggregation, statistical exploration, and visualization to understand patterns hidden inside the sales data.

The main objective is simple:

> **Turn raw e-commerce sales data into clear, useful business insights.**

---

## 🎯 Project Objectives

- Analyze overall e-commerce sales data
- Understand customer purchasing behavior
- Explore sales patterns across different demographics
- Analyze gender-wise purchasing behavior
- Compare sales across different age groups
- Identify high-performing states
- Analyze product categories and purchasing trends
- Create meaningful visualizations from the dataset
- Perform data cleaning and preparation using Python

## 🔍 Analysis Performed

### 👥 Customer & Gender Analysis

The project examines purchasing behavior across different customer groups, including:

- Gender-wise purchasing behavior
- Number of orders by gender
- Sales/revenue comparison between genders

### 🎂 Age Group Analysis

Customer demographics are analyzed to understand:

- Purchasing behavior across age groups
- Age-group distribution
- Relationship between age groups and sales

### 📍 State-wise Analysis

The analysis explores geographic purchasing patterns, including:

- Orders by state
- Sales contribution from different states
- Identification of high-performing locations

### 🛒 Product Category Analysis

Product-level analysis is performed to understand:

- Popular product categories
- Category-wise purchasing patterns
- Revenue contribution by category

### 📊 Data Visualization

Visualizations are used throughout the notebook to make patterns easier to understand and communicate.
